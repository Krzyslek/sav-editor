What this is

A fully client-side editor for Unity saves written with OdinSerializer's binary format, built around Shadow Dungeon's slot_*.sav.

How it works

  • The file is parsed into its real node tree - every entry keeps its original C# type.
  • Re-encoding an untouched file reproduces the original bytes exactly, so edits are the only difference.
  • Verify re-encodes the current tree and reports the byte delta before you download.
  • The Cheats tab applies the same edits in bulk — items it inserts are real structures taken from a save, and "best rolls" only uses values the game itself produced.

Safety

  • Nothing leaves your machine - there is no server.
  • Keep a backup of your original save. Edited saves are not guaranteed to be accepted by every game build.

Item icons

Icons are generated from each item's category and quality. To use the real sprites, drop them into assets/icons/ and list them in assets/icons/index.json.
